# Сценарий демо-видео

Рекомендуемая длина: 2-3 минуты.

## 0:00-0:15 — проблема

Геолог вручную оценивает снимок аншлифа и субъективно относит руду к одному из
трёх сортов. Наша система делает это одинаково и быстро по фотографии.

## 0:15-0:40 — архитектура

Коротко показать схему:

- P2 классификатор смотрит на снимок целиком и выдаёт сорт;
- P1 сегментация находит тальк и считает процент;
- P3 `analyze()` собирает результат;
- P4 Streamlit показывает результат геологу и формирует отчёт.

## 0:40-1:30 — интерфейс

1. Открыть Streamlit.
2. Загрузить один снимок.
3. Показать вердикт сорта.
4. Показать `talc_pct` и строку согласованности.
5. Перейти во вкладку маски, увеличить зум, сравнить с оригиналом.

## 1:30-2:10 — экспертная проверка и экспорт

1. Подтвердить вердикт геологом.
2. Показать, как исправить сорт, если модель ошиблась.
3. Скачать PDF-отчёт по снимку.
4. При пачке снимков скачать общий CSV.

## 2:10-2:40 — итог

Система даёт воспроизводимый вердикт, показывает область талька и оставляет
геологу контроль через подтверждение/правку. Даже без обученных весов интерфейс
готов к интеграции: P4 работает через стабильный контракт `core.analyze()`.
