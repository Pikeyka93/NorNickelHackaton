## Что показать жюри

1. Загрузка снимка аншлифа в Streamlit.
2. Вердикт одного из трёх сортов: рядовая / труднообогатимая / оталькованная.
3. Синяя маска талька поверх изображения.
4. Зум маски и сравнение с оригиналом.
5. Таблица метрик: доля талька, источник вердикта, уверенность, время обработки.
6. Экспертная проверка: подтвердить или исправить сорт.
7. Скачивание PDF-отчёта и CSV по пачке изображений.

## Команды перед сдачей

```bash
python -m py_compile app/main.py core/analyze.py core/report.py core/segment.py
ANALYZE_STUB=1 streamlit run app/main.py
```

Если на сервере есть зависимости и данные:

```bash
streamlit run app/main.py
uvicorn api.main:app --host 0.0.0.0 --port 8000
```
